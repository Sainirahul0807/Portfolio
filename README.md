# Rahul Saini — Portfolio

Static, responsive portfolio website for Rahul Saini, built to deploy directly
from GitHub to Vercel.

## Local preview

```bash
npm run build
python3 -m http.server 4173
```

Open `http://localhost:4173` in a browser.

## Vercel deployment

Import `Sainirahul0807/Portfolio` into Vercel. The repository uses a static
build command and has no environment variables or server runtime requirements.
